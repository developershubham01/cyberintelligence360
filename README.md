## 🌟 About the Project

**CyberIntelligence360** is a curated collection of **OSINT, security research, and ethical hacking tools** designed for:

- 🧠 Cybersecurity learners  
- 🔐 Security researchers  
- 🕵 Digital investigators  
- 💻 Ethical hackers  

The platform focuses on:

- ⚡ Performance  
- 🎯 Clean UI / UX  
- 🧩 Scalable React architecture  
- 🛡 Educational & ethical usage  

---

## ✨ Key Features

✅ Categorized security tools  
✅ Clean & modern UI

⚙️ Installation & Setup
📥 Clone the Repository
```bash
git clone https://github.com/developershubham01/cyberintelligence360.git
cd cyberintelligence360
```
📦 Install Dependencies
```bash
npm install
```
▶ Run Locally
```bash
npm start
```

Open in browser:
```bash 
👉 http://localhost:3000
```

🏗 Build for Production
```bash
npm run build
```
